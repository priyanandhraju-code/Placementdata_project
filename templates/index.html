🏠 Welcome to Placement Prediction

This machine learning project analyzes student academic, technical and educational factors to predict placement status.

Project Overview

  • Dataset: Student Placement Prediction Dataset
  • Target Variable: PlacementStatus
  • Problem Type: Binary Classification
  • Purpose: Predict whether a student will be placed

Dataset Features

  • CGPA
  • AttendancePercent
  • AptitudeTestScore
  • SoftSkillRating
  • CodingTestScore
  • MockInterview
  • CollegeTier
  • Stream
  • Specialisation
  • Hostel
  • HistoryOfBacklogs
  • CGPA_Tier
  • Semester SGPA Features
  • PlacementStatus

Machine Learning Workflow

  1. Data Loading – Load the original placement dataset.
  2. Exploratory Data Analysis – Explore distributions, correlations and placement patterns.
  3. Data Preprocessing – Clean, encode, handle missing values, detect outliers and scale the dataset.
  4. Linear Regression – Apply Linear Regression without regularization and regularized models using Ridge and Lasso.
  5. Logistic Regression – Apply Logistic Regression without regularization and regularized models using Ridge and Lasso.

Project Objective

The objective of this project is to analyze student-related factors and build machine learning models that can predict whether a student is placed.

Preprocessing Pipeline

1. Feature / Target Separation

PlacementStatus is separated as the target variable.

2. Feature Type Identification

Features are separated into numerical and categorical features.

3. Missing Value Handling

Numerical missing values are handled using median imputation. Categorical missing values are handled using the most frequent value.

4. Numerical Feature Scaling

Numerical features are scaled using StandardScaler or MinMaxScaler.

5. Categorical Encoding

Categorical features are converted into numerical representation using OneHotEncoder.

6. Train / Test Split

The dataset is divided into 80% training data and 20% testing data.
